# رواق

مساحة هادئة للمحادثات الخاصة: تكتب اسمك، تاخذ معرّفك (٦ أحرف)، ترسله لمن تحب، وتبدأ المحادثة.

## كيف يشتغل

- **بدون سيرفر وبدون حسابات:** الرسائل تنتقل مباشرة بين المتصفحين عبر WebRTC (مكتبة [PeerJS](https://peerjs.com))، ومشفّرة تلقائياً.
- **التخزين في جهازك فقط:** المحادثات محفوظة في `localStorage` على الجهازين، وما تنحفظ في أي سيرفر.
- **رابط دعوة:** زر «مشاركة الرابط» يرسل رابط مثل `…/rawaq/#to=K7M2QX`، ومن يفتحه تنفتح له المحادثة معك مباشرة.
- **توصل حتى لو الطرف الثاني مسكّر:** عن طريق صندوق بريد مشفّر على Firebase (شوف الإعداد تحت). 🕓 بانتظار الإرسال، ✓ أُرسلت، ✓✓ وصلت، ✓✓ غامقة قُرئت.
- **إشعارات الوصول والقراءة:** ✓ وصلت، ✓✓ قُرئت. ومعها مؤشر «يكتب…» وحالة الاتصال وآخر ظهور.
- **الرد على رسالة:** اسحب الرسالة على الجوال، أو استخدم زر الرد عند المرور بالماوس، والرد يبيّن الرسالة الأصلية.
- **قائمة الرسالة:** ضغط مطوّل أو كلك يمين يفتح قائمة رواق، وفيها التفاعل بالإيموجي والرد والنسخ و«حذف عندي». قائمة المتصفح نفسها ممنوعة في الموقع كله.
- **رمز QR:** رمز لرابط دعوتك، تصوّره كاميرا الجوال وتنفتح المحادثة مباشرة.
- **تطبيق قابل للتثبيت:** يتثبّت على الشاشة الرئيسية، ويفتح بدون إنترنت، ويوصلك تنبيه حتى والتطبيق مسكّر (بعد إعداد التنبيهات تحت) مع عدّاد على الأيقونة.
- **بحث** في المحادثات (Ctrl+K)، وصوت تنبيه ناعم تقدر تطفيه، وفاصل «رسائل جديدة».
- **صورة البروفايل:** من «حسابك» اضغط على صورتك. الصورة تتصغّر لـ256px وتنتقل مباشرة لأصدقائك.
- **الحظر:** من قائمة المحادثة (⋮). المحظور ما يقدر يراسلك ولا يشوف إذا كنت متصل، وتلغي الحظر من نفس القائمة أو من «حسابك ← المحظورون».
- **صور وفيديوهات بتخزين سحابي:** زر المشبك، أو اللصق، أو السحب والإفلات. الملف ينرفع على Cloudinary، والرسالة تحمل رابطه بس. الصور تتصغّر قبل الرفع وتنمسح منها بيانات الموقع (GPS).

## تفعيل رفع الصور والفيديو (Cloudinary)

1. سوّ حساب مجاني في [cloudinary.com](https://cloudinary.com).
2. من **Settings ← Upload ← Upload presets** اضغط **Add upload preset**، وخلّ **Signing mode = Unsigned**، واحفظ.
3. افتح `config.js` واكتب اسم الحساب (Cloud name) واسم الـpreset:

```js
cloud: { cloudName: 'dxyz123', uploadPreset: 'rawaq_unsigned' },
```

> روابط الملفات المرفوعة عامة، لكن ما أحد يقدر يخمّنها. الحد الأقصى في الخطة المجانية: 10 ميجا للصورة و100 ميجا للفيديو.

## توصيل الرسائل والطرف الثاني غير متصل (Firebase)

إذا الطرفين متصلين، الرسالة تمشي مباشرة بينهم. وإذا واحد منهم مسكّر رواق، الرسالة تتشفّر في جهاز المرسل وتنحط في «صندوق بريد» المستلم على Firebase Realtime Database، وأول ما يفتح رواق توصله وتنحذف من الصندوق. السيرفر يشوف كلام مشفّر بس (ECDH P-256 + AES-GCM).

1. ادخل [console.firebase.google.com](https://console.firebase.google.com) وسوّ مشروع جديد (الخطة المجانية تكفي).
2. من القائمة: **Build ← Realtime Database ← Create Database**. اختر أي موقع، وابدأ بـ **locked mode**.
3. من تبويب **Rules** الصق هذي القواعد واضغط **Publish**:

```json
{
  "rules": {
    "keys": {
      "$id": {
        ".read": true,
        ".write": "!data.exists()",
        ".validate": "newData.isString() && newData.val().length < 200"
      }
    },
    "inbox": {
      "$id": {
        ".read": true,
        "$msg": {
          ".write": true,
          ".validate": "!newData.exists() || (newData.hasChildren(['f', 'iv', 'c', 't']) && newData.child('c').isString() && newData.child('c').val().length < 600000)"
        }
      }
    },
    "push": {
      "$id": {
        ".read": true,
        ".write": true,
        ".validate": "!newData.exists() || (newData.hasChildren(['endpoint', 'keys']) && newData.child('endpoint').isString() && newData.child('endpoint').val().beginsWith('https://'))"
      }
    }
  }
}
```

4. في `config.js` داخل `db` اكتب اسم القاعدة في `instance` (مثل `rawaq-1234-default-rtdb`، يطلع في رابط صفحة القاعدة)، ورواق يعرف المنطقة لحاله. أو حط الرابط الكامل في `url`.

> بدون هالإعداد يشتغل رواق مثل قبل: الرسائل توصل بس إذا الطرفين فاتحين بنفس الوقت.

## تنبيهات الجوال والتطبيق مسكّر (Web Push + Cloudflare)

يحتاج إعداد Firebase فوق. التنبيه يقول «وصلتك رسالة جديدة» بس، بدون محتوى الرسالة، والرسالة نفسها تبقى مشفّرة في الصندوق لين تفتح التطبيق.

1. **ولّد المفاتيح:** افتح `…/rawaq/tools/vapid.html` من موقعك واضغط «ولّد المفاتيح».
2. **سوّ الـ Worker:** ادخل [dash.cloudflare.com](https://dash.cloudflare.com) (حساب مجاني) ← **Workers & Pages ← Create ← Create Worker**، سمّه `rawaq-push` واضغط **Deploy**، بعدين **Edit code** والصق محتوى `push/worker.js` كامل واضغط **Deploy**.
3. **المتغيرات:** من **Settings ← Variables and Secrets** أضف:
   - `DB_URL` = رابط Firebase (نفس اللي في `config.js`)
   - `VAPID_PUBLIC` = المفتاح العام
   - `VAPID_PRIVATE_JWK` = المفتاح الخاص، **واختر النوع Secret**
   - (اختياري) `ALLOW_ORIGIN` = `https://necors.github.io`
4. **اربطه بالموقع:** في `config.js` داخل `push` حط `publicKey` (المفتاح العام) و`worker` (رابط الـ Worker مثل `https://rawaq-push.اسمك.workers.dev`).
5. **على الجوال:** افتح رواق ← على الآيفون **مشاركة ← إضافة إلى الشاشة الرئيسية** وافتحه من الأيقونة (شرط من Apple، iOS 16.4 أو أحدث) ← اضغط «تفعيل» في بطاقة التنبيهات أو من «حسابك ← تنبيهات الرسائل».

## التشغيل

الموقع ملفات ثابتة فقط (`index.html` و`style.css` و`app.js` و`sw.js` ومجلد `vendor`)، فينرفع على أي استضافة HTTPS مثل GitHub Pages.
محلياً يكفي تشغل:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080/rawaq/
```

## سيرفر إشارة خاص (اختياري)

افتراضياً يستخدم رواق سيرفر PeerJS المجاني والعام عشان الطرفين يلقون بعض (السيرفر ما يشوف الرسائل).
إذا تبي سيرفرك الخاص، شغّل [`peer`](https://github.com/peers/peerjs-server) وعرّف الإعداد قبل `app.js`:

```html
<script>
  window.RAWAQ_CONFIG = { peer: { host: 'peer.example.com', port: 443, path: '/', secure: true } };
</script>
```
